# CP/M port documentation

The [architecture and delivery milestones](architecture.md) describe the port
of Ken Stone's original Hyperdrive and its acceptance requirements. The
[player guide](player-guide.md) is spoiler-free. The
[qualification report](qualification.md) records executed checks.

**Spoilers:** implementation rules, route transcripts, audit reports and tests
in this directory or the test suite reveal puzzles, hidden destinations and
endings. They are retained for development and verification. Players can use
the in-game HELP instead.
