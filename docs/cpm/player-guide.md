# Playing Hyperdrive

Run `HYPERDRV` at the CP/M prompt. Your yacht has been damaged, and you have
docked with a derelict cruiser to find equipment for repairs. Return useful
salvage to the yacht, then use FINISH to attempt the journey home.

Commands are case-insensitive. NORTH, SOUTH, WEST and EAST can be shortened to
N, S, W and E. LOOK describes the room. INVENTORY, INVENT, LIST and I show what
you carry. TAKE and DROP accept an object name; you can carry eleven objects.
USE operates equipment, READ examines instructions, and TRANSMAT operates the
transporter. SCORE reports your salvage value. Depositing equipment in your
yacht earns twice its carried value.

A hostile machine may attack when you attempt another action before using the
blaster. There is no elapsed-time deadline: you can read, use HELP or save first.
Repeated blaster fire becomes more dangerous as the adventure continues. Written instructions and room descriptions
contain clues. HELP remains available while you solve a puzzle. Long help text
pauses for Space or Enter; Q skips the remaining passage.

SAVE keeps your progress on disk. SAVE followed by a name selects another slot;
names contain one to eight letters, digits or underscores. LOAD restores a
slot. The default name is HYPERDRV. Replacing a save requires confirmation, and
a previous version remains as a backup. If a save was interrupted, LOAD can
offer a recoverable copy. Save that recovered game into a new slot.

QUIT returns to CP/M after confirmation. RESTART begins a new adventure after
confirmation. FINISH, also named LAUNCH, attempts repairs while you are aboard
your yacht. You can save before making that attempt.

In the Triptych browser terminal, export the disk as a separate backup.
Browser storage and a downloaded image are separate copies. Existing saved
disks require an explicit installation through the Files panel to acquire a
new application; reopening preserves the disk you already had.

This is Ken Stone's original VIC-20 Hyperdrive. The recovered program credits
Ken Stone and John Hardy and records copyright Micro Parts, 1982. John Hardy's
Hyperdrive II is a separate game.
